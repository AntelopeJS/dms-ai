## The chat says the assistant is offline

The sidecar does not answer. Click **Restart assistant** on the Overview banner. If the assistant stays offline, check that the backend did not start with `DMS_AI=0` or `NODE_ENV=production`, and that `backendUrl` points at the backend.

## A turn fails because the agent is not set up

The selected agent cannot run. Either Claude Code has no credentials, or Codex is not installed at the pinned version or not signed in with ChatGPT. The assistant never falls back to the other provider. See [Agent providers](/docs/modules/ai/configuration#agent-providers).

## Safe mode is greyed out

Safe mode needs `@antelopejs/dms-builder`. Add that module and restart the backend.

## The assistant asked me before deleting a page in Full auto

Deleting pages, tables, fields or queries always asks, in every mode. Adding or removing dependencies, and removing or moving Builder blocks, ask too, unless you turn them off under **Always ask for** in Settings.

## Can I undo a change after a week?

Only within the checkpoint retention, which Settings sets to 7, 30 or 90 days. If later change sets touched the same files, undoing one set alone may leave code that does not compile. The dialog then offers **Undo them together**.

## The session cookie is dropped when I open the dashboard from another machine

The development server, `ajs dms dev`, sets `DMS_COOKIE_SECURE` to `false` by default, so it sends the session cookie over plain HTTP. If the cookie is still dropped, check that the frontend server's environment does not set `DMS_COOKIE_SECURE=true`.

## A second dashboard tab hangs

Browsers allow six HTTP/1.1 connections per origin. Close the chat in the other tab, or serve the dashboard over HTTPS with HTTP/2.

## Two skills share a name

The assistant uses only one copy, and the Skills page marks the other as **Shadowed**. Rename one of the two skills to use both.
