# FAQ

## The chat says the assistant is offline

The sidecar does not answer. Click **Restart** on the Overview banner. Check that the backend did not start with `DMS_AI=0` or `NODE_ENV=production`, and that `backendUrl` points at the backend.

## A turn fails because the agent is not set up

The picked agent cannot run: Claude Code has no credentials, or Codex is not installed at the pinned version or not signed in with ChatGPT. The assistant never falls back to the other provider. See [Agent providers](/docs/modules/ai/configuration#agent-providers).

## Every Codex command fails with `bwrap: Can't write data to file`

The project has more than one secret file and Codex sandboxes with the system bubblewrap, which Codex 0.154 cannot use to hide two files. dms-ai gives Codex its own bubblewrap instead when this machine lets it create a user namespace. Some hosts allow that only for the system bubblewrap, for example under an AppArmor user namespace restriction. There, use Claude Code until dms-ai supports a newer Codex.

## Safe mode is greyed out

It needs `@antelopejs/dms-builder`. Add the module and restart.

## The assistant asked me before deleting a page in Auto review

Deleting pages, tables, fields or queries always asks, in every mode. Adding or removing dependencies and moving Builder blocks ask too, unless turned off in Settings.

## The chat says Auto review isn't available

Auto review needs a model and a plan that support it, and a setting that allows it. When one of them does not, the chat asks first instead, as in Ask first, and the notice names the model. Pick another model on the Settings page, or choose Ask first as the default mode on Claude Code. Codex has no Auto review.

## Can I undo a change after a week?

Only within the checkpoint retention (7, 30 or 90 days, set in Settings). Undoing a set alone when later sets touched the same files may leave code that does not compile: the dialog offers to undo those too.

## The session cookie is dropped when I open the dashboard from another machine

Over plain HTTP on an address other than `localhost`, start the frontend server with `DMS_COOKIE_SECURE=false`.

## A second dashboard tab hangs

Browsers allow six HTTP/1.1 connections per origin. Close the chat in the other tab, or serve the dashboard over HTTPS with HTTP/2.

## Two skills share a name

Only one copy is used; the other is marked Shadowed on the Skills page. Rename one of them.
